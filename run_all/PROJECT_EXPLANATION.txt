1. HOW TO RUN THE PROJECT (QUICK START)
================================================================================

You can start the entire multi-tier system using a single command:

STEP 1: Open Terminal / Command Prompt in project directory:
        cd "C:\Hackathon"

STEP 2: Run the master orchestrator script:
        python run_all.py

This single command automatically starts all three tiers in parallel:
  [1] FastAPI ML API Backend  -> http://localhost:5001 (Docs: /docs)
  [2] 100 TPS Simulator Bot   -> http://localhost:9090 (WebSocket: 8080)
  [3] Live React Frontend UI  -> http://localhost:5173

================================================================================
3. TECHNOLOGIES & TOOLS USED
================================================================================

1. PYTHON FASTAPI (Backend API Framework)
   - Modern, high-performance Python web framework for async microservices.
   - Provides `/alerts/blocked` REST API endpoint and WebSocket streaming.

2. SCIKIT-LEARN (Isolation Forest - Layer 1)
   - Unsupervised baseline anomaly score generator across 53 behavioral features.

3. XGBOOST (XGBClassifier - Layer 2)
   - Gradient boosted decision trees classifier for precise fraud risk probabilities.

4. PYDANTIC (Data Validation & Payload Aliasing)
   - Validates incoming transaction data structures and normalizes payload aliases.

5. REACT + VITE + TAILWIND CSS (Frontend UI Dashboard)
   - Instant rendering frontend with tabs, search, CSV export, freeze stream controls, and interactive modal dialogs.


================================================================================
4. HOW THE ML PIPELINE WORKS (LAYER 1 + LAYER 2)
================================================================================

• LAYER 1 (Isolation Forest): 53 features -> `layer1_anomaly_score`
• LAYER 2 (XGBoost Classifier): 56 features -> `risk_probability`
• THRESHOLD: `0.8600`
  - If `risk_probability >= 0.86` -> `ANOMALY` (Auto-Blocked)
  - If `risk_probability < 0.86`  -> `NORMAL`


================================================================================
5. PERSISTENT BLOCKED THREATS ARCHIVE & SEARCH
================================================================================

To ensure no blocked transaction is lost during high-throughput 100 TPS streams:

1. Backend Storage (`main.py` -> `BlockedAlertsStore`):
   - Every transaction flagged as `ANOMALY` or `p >= 0.86` is stored in an in-memory thread-safe store (`GET /alerts/blocked`).

2. All-Time Blocked Threats Tab (`http://localhost:5173/alerts`):
   - Displays all historical blocked threats from the entire session.
   - Includes real-time Search Bar (Search by Transaction ID, User ID, Location, Reason).
   - Includes CSV Export button (`[📥 Export Blocked Alerts CSV]`).
   - Clicking any row opens the Threat Details Modal displaying full human-readable explanations.
